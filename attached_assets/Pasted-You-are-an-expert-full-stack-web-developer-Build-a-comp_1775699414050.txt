- **Accent/Script:** Google Font — `"Great Vibes"` (for decorative script text)

### Visual Style:
- Rustic-elegant barn aesthetic
- Full-width cinematic hero sections with overlay gradients
- Soft shadows, rounded cards, subtle hover animations
- Floral/botanical SVG decorative dividers between sections
- Parallax scrolling effects on hero images
- Thin gold borders and decorative lines as accents
- Consistent warm, golden-hour photography feel

## ⚙️ TECHNICAL REQUIREMENTS

### Responsive Design:
- Mobile-first CSS
- Hamburger menu on mobile (animated slide-in drawer)
- All grids collapse to single column on mobile
- Touch-friendly tap targets

### Performance:
- Lazy loading for all images (`loading="lazy"`)
- CSS animations use `transform` and `opacity` only (GPU accelerated)
- Minify inline CSS/JS where possible

### Animations & Interactions:
- Scroll-triggered fade-in animations (use Intersection Observer API)
- Smooth page transitions
- Hover effects on all cards (lift + shadow)
- Smooth scroll for anchor links
- Active nav link highlight

### SEO & Meta:
- Each page has unique `<title>` and `<meta description>`
- Open Graph tags for social sharing
- Structured data (JSON-LD) for LocalBusiness on contact page
